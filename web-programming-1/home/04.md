# 4. otthoni gyakorlat – JavaScript és DOM

## Tanulási célok

JavaScript-fájlt kapcsolsz egy oldalhoz, eseményt kezelsz, és a DOM-on keresztül módosítod a megjelenő dokumentumot.

## Alapfogalmak

A **DOM** (*Document Object Model*) a böngésző által létrehozott, programból elérhető dokumentumfa. JavaScript segítségével elemeket kereshetünk meg, szöveget módosíthatunk, osztályt adhatunk hozzájuk, vagy felhasználói eseményre reagálhatunk.

## Feladat: téma kapcsoló

Készíts egy világos/sötét téma kapcsolót a korábbi oldalhoz. Az `index.html` végén csatold a JavaScriptet:

```html
<button id="theme-toggle" type="button">Sötét mód</button>
<script src="script.js"></script>
```

Az `style.css` fájlban:

```css
body.dark {
  color: #f8fafc;
  background: #111827;
}

body.dark section,
body.dark header,
body.dark footer {
  background: #1f2937;
}
```

Az `script.js` fájlban:

```js
const button = document.querySelector('#theme-toggle');

button.addEventListener('click', () => {
  document.body.classList.toggle('dark');
  const darkModeActive = document.body.classList.contains('dark');
  button.textContent = darkModeActive ? 'Világos mód' : 'Sötét mód';
});
```

A `querySelector` megkeresi a gombot, az `addEventListener` figyeli a kattintást, a `classList.toggle` pedig hozzáadja vagy eltávolítja a `dark` osztályt.

## Ellenőrzőlista

- [ ] A `script.js` fájl csatlakozik az oldalhoz.
- [ ] A kattintás látható változást okoz.
- [ ] A gomb felirata tükrözi az aktuális lehetőséget.
- [ ] A böngésző konzoljában nincs hiba.
