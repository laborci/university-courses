# 7. otthoni gyakorlat – Minimális Node.js-szerver

## Tanulási célok

Elindítasz egy egyszerű szerveroldali alkalmazást, amely egy HTTP-útvonalra választ küld.

## Alapfogalmak

A **Node.js** JavaScript-futtatókörnyezet, amely böngészőn kívül, például szerveren is futtat JavaScriptet. A szerver figyeli a beérkező HTTP-kéréseket, majd az útvonal és a metódus alapján választ küld.

## Feladat: `GET /time`

Az `07-node-server/` mappában hozd létre a következő fájlokat.

`package.json`:

```json
{
  "name": "node-time-server",
  "private": true,
  "version": "1.0.0",
  "scripts": {
    "start": "node server.js"
  }
}
```

`server.js`:

```js
const http = require('node:http');

const server = http.createServer((request, response) => {
  const url = new URL(request.url, `http://${request.headers.host}`);

  if (request.method === 'GET' && url.pathname === '/time') {
    const body = JSON.stringify({ time: new Date().toISOString() });
    response.writeHead(200, {
      'Content-Type': 'application/json; charset=utf-8'
    });
    response.end(body);
    return;
  }

  response.writeHead(404, { 'Content-Type': 'application/json; charset=utf-8' });
  response.end(JSON.stringify({ error: 'Az útvonal nem található.' }));
});

server.listen(3000, () => {
  console.log('A szerver címe: http://localhost:3000/time');
});
```

Indítás a mappában:

```bash
npm start
```

Ezután nyisd meg a `http://localhost:3000/time` címet. Készíts képernyőképet a működő válaszról. Leállítás: `Ctrl+C` a terminálban.

## README-be írandó magyarázat

A kliens a `/time` útvonalra `GET` kérést küld. A szerver ellenőrzi az útvonalat és a metódust, majd 200-as státuszkóddal JSON-választ ad. Más útvonal esetén 404-es választ küld. A `Content-Type` fejléc jelzi, hogy a válasz JSON-formátumú.
