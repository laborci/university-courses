# 6. otthoni gyakorlat – Nyilvános webes API használata

## Tanulási célok

Egy nyilvános API-tól aszinkron módon adatot kérsz le, feldolgozod a JSON-választ, és a három állapotot – betöltés, siker, hiba – is kezeled.

## Alapfogalmak

Az **API** (*Application Programming Interface*) olyan felület, amelyen keresztül programok kommunikálhatnak egymással. Sok webes API HTTP-n keresztül, gyakran JSON formátumban küld adatot. A `fetch()` nem blokkolja a böngészőt: a válasz később érkezik meg, ezért `async`/`await` vagy Promise használata szükséges.

## Feladat: országadatok megjelenítése

A [REST Countries API](https://restcountries.com/) nem igényel kulcsot. Az alábbi példa három információt ír ki Magyarországról.

`index.html`:

```html
<h1>Országadatok</h1>
<button id="load-button" type="button">Magyarország adatainak betöltése</button>
<p id="status" role="status"></p>
<section id="result" hidden></section>
<script src="script.js"></script>
```

`script.js`:

```js
const button = document.querySelector('#load-button');
const status = document.querySelector('#status');
const result = document.querySelector('#result');

button.addEventListener('click', loadCountry);

async function loadCountry() {
  status.textContent = 'Betöltés…';
  result.hidden = true;

  try {
    const response = await fetch('https://restcountries.com/v3.1/name/hungary?fullText=true');
    if (!response.ok) throw new Error(`HTTP hiba: ${response.status}`);

    const [country] = await response.json();
    const capital = country.capital?.[0] ?? 'nincs adat';
    const languages = Object.values(country.languages ?? {}).join(', ');

    result.innerHTML = `<h2>${country.name.common}</h2><p>Főváros: ${capital}</p><p>Népesség: ${country.population.toLocaleString('hu-HU')} fő</p><p>Nyelvek: ${languages}</p>`;
    status.textContent = 'Az adatok betöltődtek.';
    result.hidden = false;
  } catch (error) {
    status.textContent = `Hiba történt: ${error.message}`;
  }
}
```

Valós projektnél ne helyezz ellenőrizetlen külső szöveget `innerHTML`-be. Ebben a kis, ismert API-val készült példában egyszerűen tartjuk a megjelenítést; később biztonságosabb a `textContent` és DOM-elemek létrehozása.
