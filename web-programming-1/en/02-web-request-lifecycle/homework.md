# Homework 2 – The lifecycle of a web request

Create one `homework/02.md` file about loading a freely chosen, publicly available web page.

## Task

1. Give the URL you examined.
2. Describe, in no more than ten numbered steps, what happens from entering the address to the page’s first display.
3. Explain the roles of DNS, TCP, and TLS in separate short paragraphs.
4. Describe the path of the request from browser to display in short, arrow-separated steps. Use the selected URL’s domain name and identify the roles of DNS, the HTTPS connection, the server or CDN, and the browser.
5. Name two different possible failures and explain what the user would notice in each case.

Do not use personal or confidential data. The file must be understandable on its own, without attachments.
