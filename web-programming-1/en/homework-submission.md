# Homework submission

## Purpose

Homework assignments are independent written analyses of concepts covered in the lectures. Every assignment is a single, short, well-structured Markdown file.

## Public GitHub repository

Every student must create a public GitHub repository. Suggested name: `webprog1-<neptun-code>`.

Every submission must be placed in the repository’s `homework/` directory, using the two-digit session number:

```text
webprog1-<neptun-code>/
└── homework/
    ├── 01.md
    ├── 02.md
    ├── 03.md
    └── …
```

## Submission format

- There is exactly one file for each session: `homework/NN.md`.
- The file answers the relevant weekly questions in the student’s own words.
- No attachment, screenshot, program code, or separate `README.md` is required.
- If external sources are used, cite them briefly at the end of the file.
- The file must not contain personal, confidential, or login information.

The concrete task for each session is available on that session’s `homework.md` page.

## Submission method and deadlines

Specific deadlines and the review process will be announced through the course administration platform or the course information page.
