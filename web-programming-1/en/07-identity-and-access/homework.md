# Homework 7 – Analysing a sign-in flow

Create one `homework/07.md` file about a freely chosen, publicly viewable sign-in or registration flow. You do not need to—and must not—actually sign in.

## Task

1. Name the service category and the purpose of the interface you examined.
2. Identify the authentication options offered by the interface, such as password, one-time code, third-party sign-in, or passkey.
3. Distinguish authentication from authorization using one concrete example.
4. If third-party sign-in is available, describe the expected actors and steps at a high level.
5. Name three security or usability considerations you observed or would expect from the interface.
6. Explain why confidential values, cookies, and tokens from a sign-in flow must not be committed to a public repository.

Do not include account names, passwords, cookies, tokens, or personal data.
