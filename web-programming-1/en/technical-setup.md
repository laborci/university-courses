# Technical setup

Lectures are theoretical, but homework requires a few basic tools.

## Required tools

- A modern browser such as Firefox, Chrome, Edge, or Safari.
- The browser’s built-in developer tools.
- A GitHub account and public repository.
- A text editor or code editor for HTML, CSS, JavaScript, and Markdown files.
- A current long-term-support version of Node.js for later assignments.

## Not required

No prior web-development experience, paid development tool, or cloud-service account is required. Assignments are small and use built-in browser tools and locally running examples.

## Initial check

Before the first homework assignment, students should verify that they can open a local HTML file in a browser, create a public GitHub repository, and upload or commit files to it.
