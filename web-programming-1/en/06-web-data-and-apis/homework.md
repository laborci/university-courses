# Homework 6 – Analysing public API documentation

Create one `homework/06.md` file about a freely chosen, publicly documented API.

## Task

1. Name the API and the problem or service it supports.
2. Select one specific endpoint. Give its method, path, and purpose.
3. Describe the parameters accepted by the endpoint and what each one is for.
4. Show a short fictional example request and a shortened JSON response. Do not paste a large dataset.
5. Explain one expected successful and one expected error response, including a status code for each.
6. Evaluate the documentation: what makes it usable, and which information would be missing for you?

Choose only an API with publicly available documentation. Do not use your own API key or any confidential information.
