# 2. otthoni gyakorlat – CSS és reszponzív megjelenés

## Tanulási célok

Megismered a HTML és CSS külön szerepét, a külső stíluslap csatolását, az alapvető szelektorokat és a kis képernyőre való tervezés alapját.

## Alapfogalmak

A **CSS** (*Cascading Style Sheets*) a HTML-elemek megjelenését írja le: szín, betűtípus, térköz, méret és elrendezés. A HTML maradjon a tartalom és a jelentés leírása; a megjelenési szabályok kerüljenek CSS-fájlba.

Egy külső stíluslapot a HTML `head` részében kapcsolunk be:

```html
<link rel="stylesheet" href="style.css">
```

Gyakori CSS-szabály:

```css
body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  margin: 0;
}
```

A szabály bal oldalán a **szelektor**, jobb oldalán a tulajdonságok vannak. A böngésző a szabályokat a dokumentum elemeire alkalmazza.

## Feladat

Másold át vagy dolgozd tovább az első feladat bemutatkozó oldalát a `02-css/` mappában. Készíts hozzá `style.css` fájlt. Legyen olvasható, rendezett és telefonon is használható.

## Javasolt megoldás

Az `index.html` fájl `head` részébe kerüljön a stíluslap hivatkozása, a `style.css` tartalma pedig lehet például:

```css
:root {
  --ink: #1f2937;
  --surface: #f8fafc;
  --accent: #0f766e;
}

* { box-sizing: border-box; }

body {
  max-width: 900px;
  margin: 0 auto;
  padding: 1.5rem;
  color: var(--ink);
  background: var(--surface);
  font-family: system-ui, sans-serif;
  line-height: 1.6;
}

header, footer {
  padding: 1.5rem;
  background: white;
  border-radius: 0.75rem;
}

section {
  margin-top: 1rem;
  padding: 1.25rem;
  background: white;
  border-radius: 0.75rem;
}

a { color: var(--accent); }

img { max-width: 100%; height: auto; border-radius: 0.5rem; }

@media (max-width: 600px) {
  body { padding: 0.75rem; }
  header, footer, section { padding: 1rem; }
}
```

Az `img { max-width: 100%; height: auto; }` szabály megakadályozza, hogy a kép kilógjon a keskeny képernyőről. A média lekérdezés csak 600 px vagy kisebb nézetben írja felül a térközöket.

## Ellenőrzőlista

- [ ] A HTML-ben külső `style.css` hivatkozás van.
- [ ] A szöveg olvasható, a kontraszt megfelelő.
- [ ] A kép keskeny képernyőn sem lóg ki.
- [ ] Az oldal nem igényel oldalirányú görgetést telefonon.
- [ ] A HTML szerkezete továbbra is szemantikus.
