# 5. otthoni gyakorlat – Böngészőoldali állapot és tárolás

## Tanulási célok

Megérted a futás közbeni állapot és a tartós böngészőoldali tárolás különbségét, majd `localStorage` segítségével megőrzöl egy felhasználói beállítást.

## Alapfogalmak

A JavaScript-változók értéke oldal-újratöltéskor általában elveszik. A **localStorage** kulcs–érték párokat tárol a böngészőben az adott webhelyhez, ezért az érték később is elérhető. Csak szöveget tárol; összetett adatot `JSON.stringify` és `JSON.parse` segítségével kezelhetünk.

Ne tárolj `localStorage`-ban jelszót, hozzáférési tokent vagy más titkos adatot. Ugyanazon webhely JavaScript-kódja hozzáférhet az itt tárolt értékekhez.

## Feladat: téma megjegyzése

Az előző feladat téma kapcsolóját egészítsd ki ezzel a `script.js` fájllal:

```js
const button = document.querySelector('#theme-toggle');
const storageKey = 'preferred-theme';

function setTheme(theme) {
  const isDark = theme === 'dark';
  document.body.classList.toggle('dark', isDark);
  button.textContent = isDark ? 'Világos mód' : 'Sötét mód';
}

setTheme(localStorage.getItem(storageKey) ?? 'light');

button.addEventListener('click', () => {
  const nextTheme = document.body.classList.contains('dark') ? 'light' : 'dark';
  localStorage.setItem(storageKey, nextTheme);
  setTheme(nextTheme);
});
```

Teszteld: válts sötét módra, töltsd újra az oldalt, majd ellenőrizd, hogy a téma megmaradt-e. A fejlesztői eszközök **Application** vagy **Storage** paneljén a tárolt kulcsot is megtekintheted.

## localStorage, sessionStorage és cookie

| Megoldás | Meddig marad meg? | Tipikus cél |
| --- | --- | --- |
| `localStorage` | Törlésig vagy böngészőadat-törlésig | Beállítás, kis helyi lista |
| `sessionStorage` | A böngészőfül bezárásáig | Ideiglenes fülállapot |
| Cookie | A megadott lejáratig | Szerverrel megosztott állapot, például munkamenet |
