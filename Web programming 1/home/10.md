# 10. otthoni gyakorlat – Minőségi web és projektzárás

## Tanulási célok

Egy korábbi böngészőben futó feladatot három minőségi szempont szerint fejlesztesz: akadálymentesség, teljesítmény vagy használhatóság, valamint kereshetőség vagy adatvédelem.

## A minőség több szempont együttese

Egy oldal nemcsak akkor jó, ha „működik”. Fontos, hogy érthető legyen különböző felhasználóknak, gyorsan és kiszámíthatóan reagáljon, valamint ne kérjen vagy tároljon szükségtelen adatot.

| Szempont | Példa javítás | Várható hatás |
| --- | --- | --- |
| Akadálymentesség | értelmes `alt`, címkehieararchia, gombhoz szöveges felirat | segítő technológiával is érthetőbb oldal |
| Használhatóság | egyértelmű betöltési és hibaállapot | a felhasználó tudja, mi történik |
| Teljesítmény | képek megfelelő mérete, `loading="lazy"` nem kritikus képeknél | kisebb adatforgalom és gyorsabb betöltés |
| Kereshetőség | jó `title`, egyértelmű `h1`, nyelv megadása | a keresők és a böngésző jobban értelmezik az oldalt |
| Adatvédelem | szükségtelen tárolt adat eltávolítása | kisebb kockázat és kevesebb kezelt adat |

## Feladat

Válaszd ki a 2., 4., 5. vagy 6. gyakorlat egyik megoldását, másold a `10-quality/` mappába, és legalább három célzott javítást készíts. Kötelező:

1. egy akadálymentességi javítás;
2. egy teljesítményi vagy használhatósági javítás;
3. egy kereshetőségi vagy adatvédelmi javítás.

## Lehetséges javítások

### 1. Akadálymentesség

```html
<button id="load-button" type="button">Adatok betöltése</button>
<p id="status" role="status" aria-live="polite"></p>
```

A gomb érthető neve jelzi a funkcióját, az `aria-live="polite"` pedig lehetővé teszi, hogy a segítő technológia érzékelje a később megjelenő állapotüzenetet.

### 2. Használhatóság

Betöltés alatt tiltsd le a gombot, hogy a felhasználó ne indítson véletlenül több azonos kérést:

```js
button.disabled = true;
try {
  // adatlekérés
} finally {
  button.disabled = false;
}
```

### 3. Teljesítmény

Nem kulcsfontosságú képhez használhatsz lusta betöltést:

```html
<img src="profil.jpg" alt="Bemutatkozó portré" width="600" height="400" loading="lazy">
```

A megadott méretek segítenek a böngészőnek helyet foglalni a képnek, így kisebb lehet az oldal elrendezésének ugrálása.

### 4. Kereshetőség és adatvédelem

```html
<html lang="hu">
<head>
  <title>Országadatok – Webprogramozás I.</title>
  <meta name="description" content="Egyszerű országadat-megjelenítő nyilvános API-val.">
</head>
```

A cím és leírás a dokumentumról ad összefoglaló információt. Adatvédelmi javításként törölheted a korábban feleslegesen tárolt `localStorage` értékeket, vagy egyértelműen jelezheted, hogy milyen helyi beállítást tárol az oldal.

## README-minta

```md
# 10 – Minőségi javítások

## Kiinduló projekt

A 06-api feladatot fejlesztettem tovább.

## Javítások

1. **Akadálymentesség:** A betöltési állapot kapott `role="status"` és `aria-live="polite"` attribútumot. Így a képernyőolvasó felhasználó is értesül az állapotváltozásról.
2. **Használhatóság:** Adatkérés alatt a betöltőgomb letiltott. Így nem indul több párhuzamos, véletlen kérés.
3. **Kereshetőség:** Pontosabb `title`, `lang="hu"` és rövid meta leírás került az oldalba. Ez egyértelműbbé teszi a dokumentum nyelvét és témáját.
```

## Ellenőrzőlista

- [ ] Megmaradt a projekt eredeti működése.
- [ ] Három javítás készült, mindegyiknek leírtad a hatását.
- [ ] Van legalább egy akadálymentességi módosítás.
- [ ] Van legalább egy teljesítményi vagy használhatósági módosítás.
- [ ] Van legalább egy kereshetőségi vagy adatvédelmi módosítás.
- [ ] Készült friss képernyőkép.
