# Homework 3 – Interpreting an HTTP response

Create one `homework/03.md` file about an HTTP request made to a freely chosen, publicly available web page.

## Task

1. Give the URL and HTTP method of the request.
2. State the response status code and explain what it means in this situation.
3. Select three HTTP headers from the request or response. For each, explain the information it carries and why it may matter.
4. Identify the response content type and explain how it affects browser behaviour.
5. Describe how the user experience would differ if the request failed with `404`, `403`, or `500`.
6. Briefly explain which protection HTTPS provides for this request and what it does not guarantee.

Do not copy a complete HTTP response or confidential header values; include only information needed for the analysis.
