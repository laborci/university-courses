# Homework 8 – Analysing web security risks

Create one `homework/08.md` file with a security analysis of a fictional web service. Do not test or investigate a live system.

## Scenario

A university event-registration site manages user accounts, accepts registrations, and sends email confirmations. Users sign in through a browser and submit data through forms.

## Task

1. Name three assets that need protection, such as personal data, session state, or registration data.
2. Name three threats or possible failures that could affect these assets.
3. For each threat, propose at least one preventive or mitigating control.
4. Briefly explain the roles of the same-origin policy and CORS in this service.
5. Write a short error message for a failed sign-in. It must be clear to users without disclosing unnecessary security information.
6. State which responsibility belongs to the developer, the operator, and the user.

This is a defensive analytical task. Do not provide attack steps or exploitation instructions.
