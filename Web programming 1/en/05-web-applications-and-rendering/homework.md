# Homework 5 – Analysing a rendering strategy

Create one `homework/05.md` file comparing two freely chosen web services.

## Task

1. Name both services and their main user goals.
2. For each, argue whether it appears to be mainly a multi-page application, a single-page application, or another hybrid solution.
3. For each, describe the signs from which you infer client-side, server-side, or static rendering. If you cannot be certain, say so.
4. Compare the two services in terms of first load, navigation, searchability, personalization, and fault tolerance.
5. Choose one service and make a short recommendation: which rendering strategy would be appropriate for a new similar service, and why?

Base your analysis on observation and reasoning, not guesses about specific technologies.
