# Homework 4 – A web page as a browser-side document

Create one `homework/04.md` file about a freely chosen, publicly available web page.

## Task

1. Give the URL and summarize the page’s purpose.
2. Identify three semantic HTML roles or regions, such as primary navigation, main content, article, search, or footer. Explain why each role matters.
3. Choose one visible interface element and explain the likely separate roles of HTML, CSS, and JavaScript in how it works.
4. Name three different loaded resource types, such as HTML, stylesheet, JavaScript, image, or font. Explain their purposes.
5. Write a short paragraph about how use of the page would change if JavaScript failed to load.
6. Identify one browser capability the page probably uses or could use, and justify your choice.

Do not include screenshots; describe your observations in your own words.
