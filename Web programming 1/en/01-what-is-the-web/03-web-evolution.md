# Development of the web: from document web to application-like web

The web was originally used to connect documents. Today, based on the same standards, it provides interactive, personalized, real-time services that compete with installed applications in many cases.

It is worth imagining this change as more than a simple technological competition. When we read the introductory text of an organization on an early website, the browser primarily played the role of a digital newspaper or book. Today, when we plan a route on a map, edit a document together or do our studies online, the same browser is more like an application window. There is no sharp line between the two uses, and both have their place.

### 1. The beginning: linked documents

The original purpose of the World Wide Web was to allow researchers to easily reference each other's documents. The essence of hypertext is that a link within a document leads to another document or resource. This is also the basic operating principle of today's web.

The first websites were typically simple, rarely changing text pages. The author created the content and the visitor read it. There was little interaction, the user was primarily a consumer, not a creator, of the content.

### 2. Document Web and "Web 1.0"

The name "Web 1.0" is an afterthought collective term. It usually refers to the static, low-interaction, document-centric web. A typical example is a company introduction page, an early version of an online encyclopedia or a personal website.

Features:

- the content is primarily produced by the service provider;
- less frequent content updates;
- little user input;
- several separate pages and full page navigation;
- the browser is mainly a document viewer.

### 3. Participatory web and "Web 2.0"

"Web 2.0" is not a new protocol or a second version of the web. Rather, it represents a service and business approach in which users create content, communicate with each other, and services are built on data, communities, and continuous updates.

For example, social networking sites, blog platforms, video sharing sites, social encyclopedias and cloud-based collaboration tools are connected here. The user is a reader, author, evaluator and data source at the same time.

Typical changes:

- content created by users;
- personalized interfaces;
- services based on databases and APIs;
- fast, partial page updates;
- social and network effects.

### 4. The application-like web

Today's web services often do not function as a series of "pages", but as applications. An online mailer, map service, study system or word processor constantly responds to user actions, loads and saves data, can send notifications and synchronize between multiple devices.

Among other things, they make it possible to:

- program code running in the browser;
- asynchronous data communication via web APIs;
- data storage on the browser side;
- real-time communication;
- responsive and mobile-optimized interfaces;
- technologies supporting offline operation.

It is important that development does not mean the disappearance of the older model. A document-oriented, fast and simple static page can still be an excellent choice for, for example, a department information or event page.

### 5. The price of development

More complex web applications offer more possibilities, but also raise new problems:

- the amount of data to be loaded may be larger;
- more personal data is generated and managed;
- it is more difficult to ensure barrier-free use;
- more security risks appear;
- a stronger dependence on certain platforms may develop.Therefore, a "more modern" solution is not automatically better. A technology decision should always be evaluated based on the user goal, content, risk, and available resources.

## Examples

| Service | Typical approach | Reason |
| --- | --- | --- |
| University Policy Page | Document-centric web | It is primarily used for reading and rarely changes. |
| News portal | Content-based, partially dynamic web | Frequent updates, search and personalization. |
| Online mail | Application-like web | Continuous interaction, data management and synchronization. |
| Community page | Participatory Platform Web | Users create a significant portion of the content. |

## Common misunderstandings

| Claim | Clarification |
| --- | --- |
| "Web 2.0 is a new Internet." | The term denotes a service and usage approach. |
| "The static website is obsolete." | In many cases, it is a faster, cheaper and safer solution. |
| "Every modern website is a SPA." | Many modern services use a different rendering and navigation model. |

## Glossary

- **Hypertext:** system of documents linked by links.
- **Static website:** a page serving pre-made content.
- **Dynamic website:** a page that produces its content on request or based on user status.
- **Platformweb:** a service that connects users, content and other services.
- **Web application:** complex and interactive application that can be used in a browser.
