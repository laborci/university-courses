# 4. házi feladat – Egy weboldal mint böngészőoldali dokumentum

Készíts egyetlen `homework/04.md` fájlt egy szabadon választott, nyilvánosan elérhető weboldalról.

## Feladat

1. Add meg a vizsgált URL-t, és foglald össze az oldal célját.
2. Azonosíts három szemantikus HTML-szerepet vagy régiót az oldalon, például fő navigáció, fő tartalom, cikk, kereső vagy lábléc. Írd le, miért fontos az adott szerep.
3. Válassz egy látható felületi elemet, és magyarázd el külön a HTML, CSS és JavaScript lehetséges szerepét a működésében.
4. Nevezz meg három különböző betöltődő erőforrástípust, például HTML, stíluslap, JavaScript, kép vagy betűtípus. Írd le, mi a feladatuk.
5. Írj egy rövid bekezdést arról, hogyan változna az oldal használata, ha a JavaScript nem töltődne be.
6. Azonosíts egy olyan böngésző-képességet, amelyet az oldal valószínűleg használ vagy használhatna, és indokold a választást.

Ne használj képernyőképet; a megfigyeléseidet szövegesen, saját szavaiddal írd le.
