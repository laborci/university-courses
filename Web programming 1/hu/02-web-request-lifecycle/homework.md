# 2. házi feladat – Egy webes kérés életútja

Készíts egyetlen `homework/02.md` fájlt egy szabadon választott, nyilvánosan elérhető weboldal betöltéséről.

## Feladat

1. Add meg a vizsgált URL-t.
2. Írd le legfeljebb tíz, számozott lépésben, mi történik a cím beírásától az oldal első megjelenéséig.
3. Magyarázd el külön, rövid bekezdésben a DNS, a TCP és a TLS szerepét.
4. Írd le nyilakkal tagolt, rövid lépésekben a kérés útját a böngészőtől a megjelenítésig. Használd a választott URL domainnevét, és jelöld a DNS, a HTTPS-kapcsolat, a szerver vagy CDN, valamint a böngésző szerepét.
5. Nevezz meg két különböző hibalehetőséget, és mindkettőnél írd le, mit érzékelne belőle a felhasználó.

Ne használj személyes vagy bizalmas adatot. A fájlnak önmagában, külső melléklet nélkül érthetőnek kell lennie.
